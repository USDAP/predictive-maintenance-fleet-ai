# predictive-maintenance-fleet-ai
End-to-end machine learning pipeline for predictive maintenance

## Project Structure
- **`notebooks/`**: Contains the full Jupyter notebook structured for technical peer review.
- **`data/`**: Contains the dataset ingested for model training; sourced from UCI ML repository.
- **`Serialisedpkg/`**: Stores validation reports, model evaluation logs, and serialized production artifacts
- **`presentation/`**: Contains the non-technical 12-slide executive presentation deck.
- **`requirements.txt`**: Python package dependencies
- **`README.md`**: Project documentation and guide

## Quick Start
1. Clone or download the repository:
   ```bash
   git clone https://github.com/USDAP/predictive-maintenance-fleet-ai.git
   cd predictive-maintenance-fleet-ai

2. Install dependencies:
   ```bash
   pip install -r requirements.txt

3. Execute the Notebook:
   Open the Jupyter Notebook located at `notebook/ Final_Project SectionX-Team
   Aditya.ipynb` using Jupyter Lab, Jupyter Notebook, or upload it directly to Google Colab.
